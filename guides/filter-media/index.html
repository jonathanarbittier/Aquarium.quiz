Aquarium Filter Media: Mechanical, Biological, and Chemical

Media works best when each layer has a defined job. More media is not automatically better if the arrangement clogs quickly, bypasses water, or makes routine service difficult.

Reviewed October 30, 2026

Mechanical media captures particles

Coarse foam catches larger debris and protects finer stages from immediate clogging. Fine pads polish smaller suspended particles but usually need more frequent service. Aqueon notes that finer media can improve clarity at the cost of faster loading. Arrange mechanical stages from coarse to fine when the filter’s prescribed flow path allows it.

Biological media provides wet, oxygenated surface

Porous rings, foam, grids, and other permanent media support microbial communities involved in processing nitrogenous waste. The important variables are continuous water flow, oxygen, and stable handling. Replacing all biological media at once removes established surface area; stagger work when possible.

Chemical media solves a defined problem

Activated carbon adsorbs some dissolved compounds and discoloration. Other resins target specific substances. Use chemical media because the aquarium has a defined need, not because an empty basket must be filled. Exhausted media should be replaced according to the manufacturer’s instructions.

Media order follows the water path

The ideal order depends on where water enters and exits the product. Fluval explains that FX water first moves through foam before passing through central media trays. Read the diagram for your exact model; copying a basket order from a different filter can put fine media first or allow bypass.

A practical arrangement

  1. Coarse mechanical stage at the first accessible point.
  2. Finer mechanical stage where it can be removed without dismantling everything.
  3. Stable biological media in a high-flow, continuously wet area.
  4. Task-specific chemical media where water cannot bypass it.

Do not let media become a maintenance trap

An overpacked basket can reduce flow and make cleaning so unpleasant that service is delayed. Leave the space and handles needed to remove each layer. Keep a written basket map for canisters with several trays, and date disposable media when the maker specifies a replacement window.

Media is not a cure for undersizing. If water bypasses clogged pads or the owner cannot service the filter safely, adding another pouch will not solve the design problem.
