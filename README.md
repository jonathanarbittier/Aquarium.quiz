# Tankwise Aquarium Filter Finder

A lightweight static website. It uses plain HTML, CSS, and JavaScript; there is no framework, build step, API key, or dependency install.

## Open in VS Code

1. Unzip the project.
2. In VS Code, choose **File → Open Folder** and select this folder.
3. Preview with the Live Server extension, or run `python3 -m http.server 8000` in this directory and open `http://localhost:8000`.

## Deploy to Vercel

1. Create a GitHub repository and push this whole folder to it.
2. In Vercel, choose **Add New → Project** and import that repository.
3. Leave the framework preset as **Other**. There is no build command; the project root is this folder and the output is the root directory.
4. Deploy. Add a custom domain in Vercel if you have one.

You can also use Vercel CLI from this folder with `npx vercel`.

## SEO after deployment

- The page includes a focused title and description, crawl directives, social sharing metadata, a favicon, structured data, and `robots.txt`.
- Once you choose your final domain, add a canonical link in `index.html` and a `sitemap.xml` with that absolute URL. Submit the sitemap in Google Search Console.
- Search visibility takes time and depends on useful, original content and links from relevant sites; metadata alone does not create rankings.

## Before affiliate monetization

Amazon buttons currently open normal Amazon model searches and are **not tracked affiliate links**. If accepted to Amazon Associates, replace them with correctly tagged Special Links and add the required Amazon Associate statement plus a clear disclosure near those links. Verify product models and sizing details periodically.
